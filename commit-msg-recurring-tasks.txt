Recurring tasks that repeat after you finish them: Repeat field, Tasks → Recurring, Telegram

A task can now come back by itself a set time AFTER you mark it done (every N days / weeks / months / years). Finish it on day 4 instead of day 3 and the next one counts from day 4. A series keeps exactly one open task, so nothing piles up. The next task appears on its due day: in its home block if that block exists that day (like any task), otherwise unassigned on that day. Done creates the next one from every path (checkbox, Actions, calendar, Telegram buttons, phone alarm), un-done removes an untouched next one, archiving or deleting the open task pauses the series, Skip this time, and a 5-minute cron safety net creates any missing next task. UI: Repeat field when adding/editing a task, Tasks → Recurring (create, edit, pause/resume, stop, history and usual gap), ↻ badge in Tasks and Today, "Next: <day>" notice when you finish one. Telegram: "t: clean the bathroom every 3 days" (also cada 3 días), /recurring with Pause/Resume buttons, ✓ replies with the next date.
