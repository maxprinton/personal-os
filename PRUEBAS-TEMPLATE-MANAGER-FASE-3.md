# Pruebas: Template Manager fase 3 (perfiles de proyecto y rellenado)

Antes: corre **MIGRACION-0054-template-manager-perfiles.sql** en Supabase (SQL Editor → New query → pegar → Run), si todavia no esta. Luego publica con SUBIR-CAMBIOS.cmd.

1. **My details**: Templates → Projects → My details. Escribe organizacion, tu nombre como director y "Elaborado por", enfoque. Save.
2. **Perfil nuevo**: en Projects escribe "Prueba Wi-Fi" → Create. Debe traer lo de My details. Llena objetivo, patrocinador, fechas, presupuesto. Cambia a Español y escribe el nombre y el objetivo en espanol.
3. **Plan con IA**: pestana Plan → "✨ Draft with AI" en Riesgos e Hitos. Revisa el borrador → Use. Save.
4. **Copia rellenada (Word)**: Library → INI-04 Project Charter → Make a working copy → proyecto "Prueba Wi-Fi", archivo EN. Si falta algo te lo pregunta. Abre el .docx: encabezado, tablas (objetivos, alcance, hitos, interesados) y secciones (supuestos, riesgos) llenas.
5. **Espanol**: lo mismo con el archivo ES: debe salir el texto en espanol (y en ingles donde no escribiste espanol).
6. **Excel**: PLN-12 Risk Register → copia → los riesgos quedan en las filas, la fila de ejemplo gris se reemplaza, el puntaje sigue calculando.
7. **PowerPoint**: PLN-02 Project Plan on a Page → las cajas Scope, Milestones, Team, Top risks quedan llenas.
8. **Blanks**: en una plantilla, seccion Blanks → Check blanks. Cambia un campo o marca "Ask me each time" en una seccion (por ejemplo Governance) → Save. La siguiente copia te lo pregunta y "✨ Draft them with AI" propone el texto.
9. **PDF**: sube un PDF propio a una plantilla. Si es formulario, Check blanks muestra sus campos. Si es plano: + Add a spot, mueve los deslizadores, "Show preview with grid", Save. La copia escribe los valores ahi.
10. **Desactualizada**: cambia el patrocinador en el perfil → Save. En el perfil aparece "1 working copy is out of date" → Refresh (crea version nueva; las anteriores quedan).
11. **Nombre nuevo al copiar**: haz una copia escribiendo un proyecto que no existe: se crea el perfil y aparece el enlace "Complete the new project profile".
